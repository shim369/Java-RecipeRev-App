## 1. 全体の画面遷移

- 四角 = 画面(GET)、角丸 = 更新処理(POST)
- 更新処理の後は、PRGパターンで画面へリダイレクトする

```mermaid
flowchart TD
    %% ===== 画面 =====
    S01["SCR-01<br/>レシピ一覧"]
    S02["SCR-02<br/>レシピ新規登録"]
    S03["SCR-03<br/>レシピ詳細<br/>(版履歴・評価推移グラフ)"]
    S04["SCR-04<br/>レシピ基本情報編集"]
    S05["SCR-05<br/>版編集(新しい版の作成)"]
    S06["SCR-06<br/>版詳細<br/>(調理ログ一覧)"]
    S07["SCR-07<br/>版比較(差分)"]
    S08["SCR-08<br/>調理ログ登録"]
    S09["SCR-09<br/>傾向分析"]

    %% ===== 更新処理 =====
    P_CREATE(["POST 登録"])
    P_UPDATE(["POST 基本情報更新"])
    P_DELETE(["POST 論理削除"])
    P_VERSION(["POST 新しい版の保存"])
    P_TRIAL(["POST 試作を開始"])
    P_FINAL(["POST 決定版にする"])
    P_LOG(["POST 調理ログ登録"])
    P_LOGDEL(["POST 調理ログ削除"])
    P_ANALYZE(["POST 分析を実行"])

    S01 -->|新規登録| S02
    S01 -->|レシピ名| S03

    S02 --> P_CREATE --> S03
    S02 -.->|キャンセル| S01

    S03 -->|基本情報を編集| S04
    S04 --> P_UPDATE --> S03
    S03 -->|削除| P_DELETE --> S01

    S03 -->|版番号| S06
    S03 -->|最新版を元に編集| S05
    S03 -->|2つの版を比較| S07
    S03 -->|傾向分析| S09

    S06 -->|この版を元に編集| S05
    S05 --> P_VERSION -->|新しい版| S06
    P_VERSION -.->|変更なし・入力エラー| S05

    S06 --> P_TRIAL --> S06
    S06 --> P_FINAL --> S06
    S06 -->|1つ前の版と比較| S07
    S06 -->|調理ログを登録| S08
    S08 --> P_LOG --> S06
    S06 --> P_LOGDEL --> S06

    S07 -->|版番号| S06
    S07 -.->|戻る| S03

    S09 --> P_ANALYZE --> S09
    S09 -.->|戻る| S03
```

> すべての画面のヘッダーに「RecipeRev」のロゴ(→ SCR-01)とパンくずリストがある。図が見づらくなるため、それらの線は省略している。
> 存在しないID・版番号へのアクセスや、状態遷移のルールに反する操作をすると SCR-99(エラー)を表示する。

## 2. 主なシナリオ

### 2.1 配合を改良して決定版を選ぶ(このアプリの中心となる流れ)

```mermaid
sequenceDiagram
    actor U as 利用者
    participant S as RecipeRev

    U->>S: レシピ登録(SCR-02)
    S-->>U: 第1版(下書き)を作成
    U->>S: 調理ログ登録 評価3(SCR-08)
    S-->>U: 第1版が自動で試作中になる
    U->>S: 第1版を元に編集し、砂糖を増やして保存(SCR-05)
    S-->>U: 第2版(下書き)を作成
    U->>S: 第1版と第2版を比較(SCR-07)
    S-->>U: 砂糖 30g → 40g(黄)を表示
    U->>S: 調理ログ登録 評価5
    S-->>U: 第2版が試作中になる
    U->>S: 第2版を決定版にする(SCR-06)
    S-->>U: 第2版が決定版になる
    U->>S: 傾向分析を実行(SCR-09)
    S-->>U: 砂糖が多いほど評価が高い傾向を表示
```

### 2.2 決定版を切り替える(BR-05 / BR-06)
1. 第2版が決定版のとき、第4版の SCR-06 で「この版を決定版にする」を押す
2. 確認ダイアログ:「現在の決定版 第2版は試作中に戻ります。よろしいですか?」
3. サーバ側では1トランザクションで、第2版を試作中に、第4版を決定版に更新する
4. フラッシュメッセージ:「第4版を決定版にしました(第2版は試作中に戻りました)」

### 2.3 過去の版からやり直す(BR-02)
1. 第5版の評価が下がったので、評価の良かった第3版の SCR-06 を開く
2. 「この版を元に編集」→ SCR-05 では第3版の内容が入った状態で表示される
3. 保存すると **第6版**(派生元 = 第3版)ができる。第3版の中身は変わらない
